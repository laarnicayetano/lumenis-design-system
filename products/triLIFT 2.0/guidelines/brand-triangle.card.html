Isosceles triangle built to the print guideline's stated geometry (80° apex, two 50° base angles), always pointing up. Used four ways: image fill + image, background-as-image, image + line + shape, or line-only — never nested, overlapped, rotated, resized in stroke weight, or tiled into a repeating pattern.

Constructed from the documented angles — no vector triangle mark was supplied with the print guidelines (see README Caveats).
