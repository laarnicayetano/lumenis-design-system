# Working in this repo

## Playwright screenshots

When taking Playwright MCP screenshots for verification during a task, save them into `.playwright-mcp/` (already gitignored) — pass a `filename` like `.playwright-mcp/whatever.png`, not a bare filename. Don't leave screenshot files in the repo root or other tracked directories. Delete files after you are done using them.

## Claude Design compatibility (`_ds_manifest.json`)

`_ds_manifest.json` is generated by Claude Design's own scanner, not hand-written — see `docs/claude-design-manifest.md` for the schema and what's currently stale (the `cards` section, since guidelines/component specimens moved from `.card.html` to `.tsx`). There are real open questions about how that scanner actually works (committed-source requirement? does it overwrite the manifest on its own sync? is a stale entry cosmetic or load-bearing?) that this repo can't answer from the outside.

**Before restructuring source layout, changing file conventions, or hand-editing `_ds_manifest.json` to "fix" Claude Design compatibility: ask, don't assume.** Propose the change and its tradeoffs, and where the answer depends on how Claude Design's scanner actually behaves, say so explicitly rather than guessing — verifying directly in Claude Design is worth more than inference from this file's current contents.
