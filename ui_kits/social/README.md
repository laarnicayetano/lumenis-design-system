# Social formats

1080×1080 posts on the brand's 6×6 grid (36 squares, 56px margins). The wordmark is exactly 2 columns wide (29.8% of the format) and sits in a corner; the Hero "L" is 1 row tall (16.6%) or half a row.

Four sanctioned recipes, one per tile in `index.html`:
1. **Functional split** — photography in the upper band, headline and mark beneath.
2. **Inspirational** — headline only, Hero "L" in one word, mark bottom-left and symbol top-left facing diagonally.
3. **Colour field** — a single sub-brand accent as the full background, Arizona Mix on 1–2 words.
4. **Black and white statement** — long statement plus bullets, never boxed.

Minimum type sizes at 1080²: headline 52pt, subhead/body 40pt, caption 24pt. Tiles here are rendered small for the card; scale the same proportions up to 1080.
