# Email template

Single 640px table-based layout, safe for Outlook and Gmail.

Per guidelines p.32, email is the one surface where **Arial is the correct typeface** — Arizona is not webfont-safe in mail clients, so every rule here uses `Arial, Helvetica, sans-serif` at the brand's proportions (uppercase 38px/0.95 headline, 18px/1.39 body, 12px/1.14 caps captions).

Structure: white header with the wordmark → black hero band with kicker + all-caps headline → photography band on #F2F2F2 → body copy → single black CTA (squared, no radius) → one hairline-separated cross-link → black footer with legal and unsubscribe.

Swap the accent by changing the hero band background to one sub-brand colour — one per send, never two.
