# Slide templates

Seven 1280×720 slide types, each a standalone HTML file so it can be lifted straight into a deck. No slide template was supplied with the brand materials — these are built from the guidelines' communication-format rules (split layouts, one accent per surface, all-caps titles, mark in a corner).

| File | Type |
| --- | --- |
| `01-title.html` | Title — black field, Hero "L" |
| `02-section.html` | Section divider — one sub-brand accent, large icon |
| `03-split.html` | Content — type half, photography half |
| `04-stats.html` | Proof points on hairline rules |
| `05-quote.html` | Practitioner testimonial |
| `06-products.html` | Portfolio grid |
| `07-closing.html` | Sign-off, right aligned |

Body text never drops below 22px at this size; titles run 44–88px with leading at ~90%.
