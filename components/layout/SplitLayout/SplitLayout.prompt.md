The brand's core composition: split the format in two — type on one side, photography or a single accent on the other.

```jsx
<SplitLayout ratio="5fr 7fr">
  <SplitPanel><Headline heroL="UNVEIL">Unveil the best in you</Headline></SplitPanel>
  <SplitPanel tone="image" image="/hero.jpg" />
</SplitLayout>
```

Use `direction="column"` for the horizontal split. Type panels sit on white, black, or one accent colour — never over a busy photograph.
